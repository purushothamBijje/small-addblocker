# System-Wide Ad Blocker Tool

You can share this tool with any friend using Windows.

### Files Created:
- [Install-AdBlocker.bat](file:///C:/Adds/Install-AdBlocker.bat)

### How Your Friends Can Use It:
1. Copy or send them the `Install-AdBlocker.bat` file.
2. Right-click `Install-AdBlocker.bat` and select **Run as administrator** (or double-click it and accept the UAC prompt).
3. Type `1` to turn on ad blocking, or `2` to restore default settings.

### What It Does:
- Applies AdGuard DNS (`94.140.14.14`, `94.140.15.15`) across all active network adapters.
- Automatically flushes DNS cache.
- Blocks ads, banners, and trackers in all Windows desktop apps, games, and web browsers without needing third-party software.

## How to Use System-Wide Ad Blocking on Mobile (Android & iPhone)

You do not need to install any apps. Both Android and iOS support native Private DNS to block ads across all mobile apps, games, and mobile browsers.

### Android Setup (Takes 30 seconds):
1. Open **Settings** on your phone.
2. Go to **Network & internet** (or **Connections** / **More connection settings**).
3. Tap **Private DNS**.
4. Select **Private DNS provider hostname**.
5. Type:
   dns.adguard-dns.com
6. Tap **Save**.

### iPhone / iPad (iOS Setup):
1. Open Safari on your iPhone.
2. Go to `https://adguard-dns.io/en/public-dns.html`.
3. Choose **Method 2: Configuration profile**.
4. Download the profile, go to **Settings > Profile Downloaded**, and tap **Install**.

Once applied, all in-app ads, mobile game banner ads, and website pop-ups are automatically blocked on both Wi-Fi and mobile data.
